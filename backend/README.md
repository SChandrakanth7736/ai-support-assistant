# Backend

This directory is reserved for the Java/Spring Boot backend described in the master project guide.

## Current status

Stage 0 creates the backend workspace only. The source and resource directories are placeholders; there is no application code, Maven build, or runnable service yet. Backend implementation starts in Stage 1.

## Planned layout

- `src/main/java/` — Java application source.
- `src/main/resources/` — application configuration and resources.
- `src/test/java/` — backend tests.

See the [master project guide](../AI_Support_Assistant_ServiceNow_Interview_Project_Guide.md) for the staged backend plan.
